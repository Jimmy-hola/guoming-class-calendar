# 國三班網頁行事曆

學生查看網址：**https://jimmy-hola.github.io/guoming-class-calendar/**

手機、電腦打開都能看。資料更新後約 1 分鐘網站就會同步。

> 📋 專案進度、待辦與決策請看 **[工作紀錄.md](工作紀錄.md)**（人與 AI 共用的狀態檔）。

## 日常更新流程（最常用）

1. 打開 `data/` 資料夾裡要改的 CSV（可用 Excel 或文字編輯器）
2. 改完存檔
3. **Mac**：雙擊 `發布.command`　／　**Windows**：雙擊 `發布.bat`
4. 看到「✅ 發布成功」即完成

> 兩台電腦都會用的話：**改資料前先雙擊一次發布腳本**（它會先 `git pull` 把另一台的修改拉下來），改完再發布一次，避免兩邊衝突。

## data/ 各檔案的用途

| 檔案 | 內容 | 什麼時候改 |
|---|---|---|
| `設定.csv` | 網站標題、課表生效日、行事曆結束日、**高名模考週**與**暑訓模考週**開始日 | 模考週日期調整時改對應那格 |
| `課表.csv` | 每週固定課表（週幾、時間、科目、活動）→ 顯示在網頁「📋 課表」視窗 | 課表異動時 |
| `暑訓進度.csv` | 暑訓（下午）的日期、科目、冊別（行事曆上為全天標籤） | 暑訓進度調整時 |
| `特殊日.csv` | 停課（整段日期不排課）、備註 | 臨時停課、補課公告 |
| `複習卷進度.csv` | 哪天哪個時段考哪科第幾回 | 進度調整、開學後新增排程 |
| `複習卷清單.csv` | 140 回複習卷的範圍目錄（對照用） | 通常不用改 |
| `重要日程.csv` | 各校段考、學校模考、畢業旅行、特殊節日等（整天事件） | 拿到學校日程時填入 |

> 💡 用 Excel 編輯 CSV：直接雙擊開啟即可（檔案已是 UTF-8 含 BOM 格式）。**另存時請選「CSV UTF-8 (逗號分隔)」**，不要選一般 CSV，否則中文會變亂碼。

### 常見異動範例

**臨時停課一天**（例如 8/12 颱風假）→ `特殊日.csv` 加一列：
```csv
2026-08-12,2026-08-12,停課,颱風停課,當日課程順延
```
停課當天的所有課程會自動從行事曆消失。

**某回複習卷改期** → 在 `複習卷進度.csv` 找到那一列，改日期即可。

**新增複習卷場次** → `複習卷進度.csv` 加一列，只要填日期、時間、科目、第幾回，
範圍說明會自動從 `複習卷清單.csv` 帶出來：
```csv
2026-09-05,09:30,11:00,歷史,10,
```

**新增學校日程**（例如某校段考）→ `重要日程.csv` 加一列：
```csv
2026-11-05,2026-11-06,某某國中第二次段考,
```

**模考週改期** → 改 `設定.csv` 的「模考週開始」（高名模考，晚上測輔時段）或「暑訓模考週開始」（暑訓學生，下午）為那週的星期一，五天模考（一國文、二英文、三數學、四自然、五社會）會自動產生。

⚠️ CSV 規則：科目名稱要和 `複習卷清單.csv` 一致（公民要寫「公民與社會」）；日期格式 `2026-08-12`；時間格式 `19:30`。

## 第一次在新電腦（Windows 筆電）設定

1. 安裝 [Git](https://git-scm.com/download/win) 與 [Node.js](https://nodejs.org/)（都用預設選項一路下一步）
2. 開啟「命令提示字元」，輸入：
   ```
   git config --global user.name "你的名字"
   git config --global user.email "你的Email"
   cd %USERPROFILE%\Documents
   git clone https://github.com/Jimmy-hola/guoming-class-calendar.git
   ```
   第一次 push 時會跳出 GitHub 登入視窗，登入一次即可。
3. 之後就到 `Documents\guoming-class-calendar` 改 CSV、雙擊 `發布.bat`

## 紙本進度表（貼教室、給主管）

網站右上角「🖨 紙本進度表」（或直接開 `print.html`）→ 點「列印」→ 印表機選**橫向**，
每個月自動一頁 A4，黑白列印也清楚。排課修改後重新發布、重新列印即是最新版。

## 本機預覽（發布前先看看）

```
node tools/serve.mjs
```
然後瀏覽器開 http://localhost:8765/ （Mac/Windows 都可用）

## 架構說明（給之後維護的人）

- 純靜態網站，無後端：`tools/build.mjs` 讀 `data/*.csv` → 產出 `docs/events.json`，`docs/index.html` 用 FullCalendar 顯示
- 託管：GitHub Pages（main 分支 `/docs` 目錄），push 後自動部署
- 行事曆只顯示三大類：暑訓（全天標籤）、複習卷＋高名模考、重要日程＋停課備註；每週固定課表在網頁「📋 課表」視窗，停課區間的暑訓自動跳過
- 之後若要做網頁管理後台，資料層（CSV→JSON）可直接沿用
