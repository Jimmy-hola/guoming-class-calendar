# 國三班網頁行事曆

學生查看網址：**https://jimmy-hola.github.io/guoming-class-calendar/**

手機、電腦打開都能看。資料更新後約 1 分鐘網站就會同步。

> 📋 專案進度、待辦與決策請看 **[工作紀錄.md](工作紀錄.md)**（人與 AI 共用的狀態檔）。日常改資料可先看 **[維護指南.md](維護指南.md)**。

## 日常更新流程（最常用）

1. 在私有的「班務系統」修改事件、堂次異動、高名模考，或從「行事曆 → ⚙ 公開設定」調整課表、暑訓、複習卷與公布範圍。
2. 定案後勾選「已確認」與「公開」。
3. 到「行事曆 → 👁 公開預覽」，檢查差異與實際網頁，可切成手機寬度。
4. 檢查通過後按「確認並發布」。

> Windows 與 Mac 共用同一套流程。兩台輪流使用時，離開目前電腦前先提交並推送，換到另一台先拉取；系統會阻擋落後遠端或混有其他未提交修改的發布。

班務系統資料庫是唯一維護來源。`data/*.csv` 是班務系統預覽／發布時產生的輸出；`發布.bat`／`發布.command` 與直接改 CSV 只保留作災難復原備援，不是日常入口。

## data/ 各檔案的用途

| 檔案 | 內容 | 什麼時候改 |
|---|---|---|
| `設定.csv` | 網站標題、課表生效日、行事曆結束日、**公布截止日**、**紙本公布截止日**、暑訓模考週開始日 | 日常從班務系統「⚙ 公開設定」修改 |
| `高名模考.csv` | 由班務系統產生的高名模考實際日期、起訖時間、科目與範圍 | 日常不要直接改 |
| `課表.csv` | 每週固定課表（週幾、時間、科目、活動）→ 顯示在網頁「📋 課表」視窗 | 日常從班務系統「⚙ 公開設定」修改 |
| `暑訓進度.csv` | 暑訓（下午）的日期、科目、冊別（行事曆上為全天標籤） | 日常從班務系統「⚙ 公開設定」修改 |
| `特殊日.csv` | 由班務系統產生的停課、備註 | 日常不要直接改 |
| `複習卷進度.csv` | 哪天哪個時段考哪科第幾回 | 日常從班務系統「⚙ 公開設定」修改 |
| `複習卷清單.csv` | 140 回複習卷的範圍目錄（對照用） | 日常從班務系統「⚙ 公開設定」修改 |
| `重要日程.csv` | 由班務系統產生的公開活動、加課調課與重要日程 | 日常不要直接改 |
| `模擬考日期及範圍.csv` | 從照片整理的 115 學年度模擬考來源資料（官方日期、試卷、範圍）；`高名模考.csv` 依此排出 | 通常不用改，調整模考請改 `高名模考.csv` |

> 只有班務系統無法使用、進行災難復原時才直接改 CSV；平常直接修改會在下次由班務系統發布時被覆蓋。

### 常見異動範例

**臨時停課一天**（例如 8/12 颱風假）→ 在班務系統行事曆新增「停課」事件，確認後執行停課並勾選「已確認＋公開」。

**某回複習卷改期／新增場次** → 到班務系統「行事曆 → ⚙ 公開設定 → 進階公開資料」修改 `複習卷進度.csv`，再產生公開預覽。

**新增學校日程**（例如某校段考）→ 在班務系統行事曆新增事件；需要較短的月曆文字可另填短標籤，內部與公開標題／內容也可分開。

**高名模考改期** → 在班務系統「模考管理 → 設定本回」修改實際日期、時間與公開範圍；定案後勾「已確認」與「公開」，再到公開預覽確認。實際考程可以跨到週六，不再假設固定一～五晚上。
**暑訓模考週改期** → 到班務系統「⚙ 公開設定」改「暑訓模考週開始」。

**公布更多行程** → 到班務系統「⚙ 公開設定」選精確的「公布截止日」，或用本月底／下月底快捷鍵；紙本可另設截止日。

⚠️ CSV 規則：科目名稱要和 `複習卷清單.csv` 一致（公民要寫「公民與社會」）；日期格式 `2026-08-12`；時間格式 `19:30`。

## 第一次在新電腦設定

1. 安裝 [Git](https://git-scm.com/download/win) 與 [Node.js](https://nodejs.org/)（都用預設選項一路下一步）
2. 開啟「命令提示字元」，輸入：
   ```
   git config --global user.name "你的名字"
   git config --global user.email "你的Email"
   cd %USERPROFILE%\Documents
   git clone https://github.com/Jimmy-hola/guoming-class-calendar.git
   ```
   第一次 push 時會跳出 GitHub 登入視窗，登入一次即可。
3. Windows 以 `啟動.bat` 開班務系統；Mac 以 `啟動.command` 啟動。日常從班務系統預覽與發布，不直接改公開 CSV。

## 紙本進度表（貼教室、給主管）

網站右上角「🖨 紙本進度表」（或直接開 `print.html`）→ 點「列印」→ 印表機選**橫向**，
每個月自動一頁 A4，黑白列印也清楚。排課修改後重新發布、重新列印即是最新版。

## 本機預覽（發布前先看看，手機也能測）

**Mac**：雙擊 `預覽.command`　／　**Windows**：雙擊 `預覽.bat`

- 瀏覽器會自動跳出 **QR code 頁面**，手機掃描就能預覽（手機需與電腦連同一個 Wi-Fi／熱點；開熱點的那支手機也可以直接掃）
- 電腦自己看：http://localhost:8765/
- 預覽期間 GitHub 線上版完全不受影響，試到滿意再雙擊發布腳本
- **關閉視窗即停止預覽**
- 手動跑也行：`node tools/serve.mjs`，啟動訊息會列出手機網址與 QR 頁網址
- ⚠️ iPhone Safari 若顯示「僅限 HTTPS」錯誤，在網址列完整輸入含 `http://` 與 `:8765` 的網址即可

## 架構說明（給之後維護的人）

- 純靜態網站，無後端：`tools/build.mjs` 讀 `data/*.csv` → 依 `設定.csv` 的「公布截止日」產出 `docs/events.json`，`docs/index.html` 顯示手機優先行事曆
- 託管：GitHub Pages（main 分支 `/docs` 目錄），push 後自動部署
- 行事曆只顯示三大類：暑訓（全天標籤）、複習卷＋高名模考、重要日程＋停課備註；每週固定課表在網頁「📋 課表」視窗，停課區間的暑訓自動跳過
- 之後若要做網頁管理後台，資料層（CSV→JSON）可直接沿用
