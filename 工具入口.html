國三行事曆本機工具

工具入口

這一頁把「預覽」、「手機 QR code」、「發布」整理在同一個地方。 如果你不熟 Git、Node 或命令列，照著卡片順序操作就可以。

最常用流程

  1. 改完 data 資料夾裡的 CSV。
  2. 先按 預覽，確認電腦和手機看起來都正常。
  3. 確認無誤後，再按 發布 上傳到 GitHub Pages。
不確定時，先預覽，不要急著發布。

雙擊工具

請依你的電腦系統選擇工具。若瀏覽器沒有直接執行，請回到資料夾裡雙擊同名檔案。

預覽與手機 QR code

用在正式發布前。它會啟動本機網站，並打開 QR code 頁面，讓手機在同一個 Wi-Fi 下掃描預覽。

Windows 預覽 Mac 預覽 開 QR code 頁
node tools\serve.mjs

發布到 GitHub Pages

用在資料確認無誤後。它會重新產生網站資料，提交變更，並推送到 GitHub，讓線上網站更新。

Windows 發布 Mac 發布 開線上網站
node tools\build.mjs

我現在該按哪一個？

只是想看目前做得怎樣 按「預覽」。這不會上傳，不會影響線上網站。
要讓手機掃 QR code 先按「預覽」，再開 QR code 頁。手機和電腦要連同一個 Wi-Fi。
已經確認資料正確 按「發布」。發布後 GitHub Pages 通常需要等一下才會更新。

背後實際做了什麼？

data 資料夾 放行事曆來源 CSV，例如課表、特殊日、複習卷、模擬考日期。
tools/build.mjs 把 CSV 轉成網站使用的 docs/events.json。
tools/serve.mjs 開本機預覽網站，網址通常是 http://localhost:8765/。

常見狀況

點按工具後沒有反應 瀏覽器可能阻擋直接執行 bat 或 command。請回到資料夾，直接雙擊「預覽.bat」或「發布.bat」。
手機打不開預覽 確認手機和電腦在同一個 Wi-Fi。若仍不行，先用電腦開 http://localhost:8765/qr。
發布時出現 GitHub 錯誤 通常是網路、登入權限或遠端資料需要同步。先不要重複亂按，把錯誤訊息截圖或貼給維護者。
線上網站還沒更新 GitHub Pages 可能需要等待一小段時間。先重新整理頁面，或等 1 到 3 分鐘再看。

建議把這個檔案當作入口：先預覽，確認後再發布。
